# Sky Fitness Gym - Vasai West 💪

A premium, high-energy landing page designed and developed for a local 24/7 fitness center in Vasai. This project was built to establish a strong digital presence for the gym and streamline their lead generation process.

## 🚀 Live Demo
[Click here to view the live website](https://mrshaikh440.github.io/sky-fitness-vasai/) *(Open on mobile for the best experience!)*

## ✨ Key Features
*   **Beast Mode UI/UX:** A dark, aggressive, and highly motivating theme tailored for a fitness environment.
*   **Dynamic Animations:** Integrated AOS (Animate On Scroll) for smooth transitions and a custom CSS splash screen preloader.
*   **Functional Lead Capture:** Connected with Web3Forms to instantly send "Free Trial" requests directly to the gym owner's email without backend setup.
*   **Fully Responsive:** Optimized flawlessly for Mobile, Tablet, and Desktop screens using Tailwind CSS.
*   **Anti-Theft Security:** Basic client-side security implemented to disable right-click, inspect element, and text selection.

## 🛠️ Technologies Used
*   **HTML5** (Semantic Structure)
*   **Tailwind CSS** (Styling & Responsiveness via CDN)
*   **Vanilla JavaScript** (Interactions & DOM Manipulation)
*   **Web3Forms** (Serverless Form Submission)
*   **FontAwesome** (Icons)

## 📌 Project Story (The Barter Deal)
This project is an example of proactive freelancing. Sky Fitness is a top-rated gym (5.0 stars on Google) in Vasai but lacked an official website. I designed this premium landing page and pitched it to the owner in exchange for a barter deal (Website setup in exchange for a 1-year gym membership).
